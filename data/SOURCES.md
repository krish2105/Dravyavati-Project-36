# Data Sources

Every layer used in this atlas is recorded here with a public URL and access date **before**
it is used anywhere else in the repo. See `CLAUDE.md` for the full provenance rule. Practical
test: a stranger with no private access should be able to rebuild every file in this repo from
the URLs below.

| Layer | Source | Access | Notes |
|---|---|---|---|
| Dravyavati River / Amanishah Nala channel geometry (21 way segments, `natural=water`, name ~ "Dravyavati\|Amanishah") | OpenStreetMap, via Overpass API (`overpass-api.de/api/interpreter`) | 2026-08-18 | Used in the `/atlas` prototype shell and as the base geometry for `src/geo/alignment.py`'s corridor reconstruction. © OpenStreetMap contributors, ODbL. |
| Jaipur Outer Ring Road / NH-148C | OpenStreetMap, via Overpass API | 2026-08-18 | `ref=NH148C` / `name~"Ring Road"`. Its intersection with the river geometry above is used as the corridor's southern endpoint in `src/geo/alignment.py` (chosen over the press-reported "Bombay Hospital" landmark, which sits ~6.4 km from the mapped channel). © OpenStreetMap contributors, ODbL. |
| Project endpoints & length ("Majar Dam" north, "beyond Goner on the Ring Road" / "Bombay Hospital on Mahal Road" south, 36 km) | Press coverage: [First India](https://firstindia.co.in/news/india/dravyavati-river-elevated-road-dpr-process-begins-1782790440), [The DeepState](https://thedeepstate.in/article/36-km-six-lane-elevated-road-planned-along-dravyavati-river-to-transform-jaipur-), [ThePrint](https://theprint.in/india/rajasthan-govt-exploring-elevated-corridor-along-dravyavati-river-in-jaipur/2878789/) | 2026-08-18 | Used to identify the corridor's approximate endpoints for reconstruction (pack §1/§4). No independently-verified public coordinate exists for "Majar Dam" itself — see `ASSUMED_NORTH_ENDPOINT_UNCERTAIN` in `src/geo/alignment.py`; the river geometry's own northern extent is used as a practical proxy instead of guessing a coordinate. |
| "Mazar" dam historically on the Amanishah Nala, near Sikar Road | [JaipurUncharted — traditional water systems](https://jaipuruncharted.in/the-city-of-jaipur-and-its-traditional-water-systems/) | 2026-08-18 | Corroborates that a "Majar/Mazar" dam is a real feature on this exact nala in the north Jaipur area, but does not give coordinates precise enough to snap to. |
| Ring Road NH designation confirmation | [Wikipedia — Ring Road, Jaipur](https://en.wikipedia.org/wiki/Ring_Road,_Jaipur) | 2026-08-18 | Confirms NH-148C is the Jaipur Ring Road referenced in the pack's endpoint description. |
| IRC:86-2018 Table 8.2 — Minimum Radii of Horizontal Curves by design speed | [IRC:86-2018, law.resource.org mirror](https://law.resource.org/pub/in/bis/irc/irc.gov.in.086.2018.pdf) (§8.3, p.29) | 2026-08-19 | 60 km/h → 130m (7% SE) / 150m (4% SE); 70 km/h → 175m / 200m; 80 km/h → 230m / 265m. Used by `src/scoring/interfaces.py` constraint 07 (curve severity). Per CLAUDE.md invariant 2, this is transcribed from the actual published table, not recalled from memory. |
| Building footprints — `building=*` within the corridor buffer | OpenStreetMap, via Overpass API | 2026-08-19 | **Substitutes for Google Open Buildings v3** (pack §4's named source). v3's public S2-level-4 CSV/FlatGeobuf mirrors cover ~13-14 GB per cell and, even in the spatially-indexed FlatGeobuf form, a bbox-filtered remote read over our ~40km corridor did not complete after two attempts (90s+ each) — impractical to fetch within this session's time/resource bounds. OSM building coverage in central Jaipur is reasonably dense; peripheral/peri-urban segments will read lower confidence as a result. Documented as a deviation, not silently swapped. |
| WorldPop India population density, 2020, 1km | [WorldPop Hub](https://hub.worldpop.org/geodata/summary?id=41746), direct: `data.worldpop.org/GIS/Population_Density/Global_2000_2020_1km/2020/IND/ind_pd_2020_1km.tif` | 2026-08-19 | Pack §4 names "WorldPop 100m or Meta HRSL"; the 100m product is tiled sub-nationally without one stable direct URL, so the national 1km product is used instead — coarser, still real WorldPop data, CC-BY 4.0. |
| Copernicus DEM GLO-30, tile N26/E075 | [AWS Open Data Registry — Copernicus DEM](https://registry.opendata.aws/copernicus-dem/), direct: `copernicus-dem-30m.s3.amazonaws.com/Copernicus_DSM_COG_10_N26_00_E075_00_DEM/...DEM.tif` | 2026-08-19 | Public, no-sign-request S3 bucket. One 1°×1° tile covers the full corridor. |
